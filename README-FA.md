# پلتفرم یکپارچه CRM و باشگاه مشتریان پویا پلاستیک — نسخه ۲.۲

این نسخه بر پایه تطبیق نسخه ۲.۱.۱ با پاسخ‌های مدیر شرکت به پرسش‌نامه ۱۳۸ سؤالی تکمیل شده است. فروش و پروژه، موتور وفاداری، حفظ مشتری، صدای مشتری، شبکه نمایندگان، محصول و قیمت، حمل‌ونقل و تبادل داده سپیدار در یک چرخه واحد کار می‌کنند.

## اجرای دمو روی لپ‌تاپ ویندوز (مناسب مبتدی)

### ۱) فقط یک‌بار Node.js را نصب کنید

1. وارد `https://nodejs.org` شوید.
2. نسخه **LTS** (ترجیحاً Node.js 20 یا جدیدتر) را دانلود کنید.
3. فایل نصب را باز کنید و در همه مراحل `Next` بزنید.
4. پس از پایان نصب، یک‌بار لپ‌تاپ را Restart کنید.

### ۲) دمو را باز کنید

1. فایل ZIP را از حالت فشرده خارج کنید (`Extract All`).
2. وارد پوشه `deploy` شوید.
3. روی فایل `demo-windows.bat` دوبار کلیک کنید.
4. پنجره سیاه را نبندید؛ مرورگر خودکار روی `http://127.0.0.1:3000` باز می‌شود.

فایل اجرای ویندوز عمداً فقط از متن انگلیسی ساده استفاده می‌کند تا در نسخه‌های مختلف CMD با خطای کدگذاری فارسی روبه‌رو نشود.

این دمو به PostgreSQL و نصب پکیج‌های npm نیاز ندارد. اطلاعات نمایشی داخل خود برنامه است و با Refresh به حالت اولیه برمی‌گردد.

## ورود به دو محیط دمو

### پنل مدیر باشگاه

- آدرس: `http://127.0.0.1:3000/login`
- در حالت دمو هر ایمیل و رمز غیرخالی پذیرفته می‌شود.
- نمونه ایمیل: `admin@loyalty.com`
- نمونه رمز: `Admin@123456`

### پنل عضو

- از پایین منوی مدیریت روی «پیش‌نمایش پنل عضو» بزنید؛ یا مستقیماً به `http://127.0.0.1:3000/club/login` بروید.
- موبایل نمونه: `09121111111`
- کد یک‌بارمصرف دمو: `123456`

### پنل نماینده

- از پایین منوی مدیریت روی «پنل نماینده» بزنید؛ یا مستقیماً به `http://127.0.0.1:3000/representative` بروید.
- در دمو، اطلاعات یک نماینده سطح A و پروژه‌های معرفی‌شده از قبل آماده است.

## مسیر پیشنهادی ارائه دمو (۱۲ دقیقه)

1. **مرکز عملیات رشد:** سهم کانال‌های پروژه، نماینده و مستقیم؛ عملکرد منبع سرنخ و پراکندگی جغرافیایی را نشان دهید.
2. **بانک پیمانکاران:** پرونده ۳۶۰ درجه پیمانکار شامل خرید، پروژه، سطح و ریسک ریزش را توضیح دهید.
3. **محصول و قیمت:** کاتالوگ یونولیت و پنل 3D و قواعد تخفیف نقدی، حجمی، پروژه‌ای و نمایندگی را نشان دهید.
4. **اهداف و حمل:** پیشرفت هدف فروش و دفتر مزایای حمل بر اساس سطح، خرید و امتیاز را نمایش دهید.
5. **استعلام‌های عضو:** وارد پنل عضو شوید و یک استعلام قیمت ثبت کنید؛ تأکید کنید این بخش فروشگاه اینترنتی نیست.
6. **قیف فروش:** کانبان، منبع سرنخ، نام و قیمت رقیب و دلیل باخت را نشان دهید.
7. **باشگاه مشتریان:** سطح، امتیاز چندبعدی، کیف پول، پاداش و مأموریت‌ها را مرور کنید.
8. **رادار حفظ مشتری:** Cron ساعت ۲، قانون ۱٫۵ برابر، Web Push و پنجره بازگشت ۲۵۰ مشتری را نمایش دهید.
9. **شبکه نمایندگان:** صف تأیید پروژه، مشتری نهایی، فعال‌سازی تخفیف و امتیاز معرفی را نشان دهید.
10. **صدای مشتری:** CSAT، هپی‌کال، موعد پاسخ و هشدار عبور از SLA شکایت را توضیح دهید.
11. **کیفیت داده:** نام‌های مشابه را نشان دهید و توضیح دهید ادغام فقط پس از تأیید انسانی انجام می‌شود.
12. **سپیدار:** ورود و خروج Excel و پردازش گروهی فاکتورها را جمع‌بندی کنید.

## ساختار پروژه

```text
crm-frontend/   رابط React، دمو آفلاین و پنل عضو
crm-backend/    APIهای Express، موتور وفاداری و Prisma
deploy/         اجرای دمو و فایل‌های استقرار
```

## اجرای توسعه‌ای

پیش‌نیاز: Node.js و PostgreSQL.

### بک‌اند

```bash
cd crm-backend
cp .env.example .env
npm ci
npx prisma migrate deploy
npx prisma db seed
npm start
```

مقادیر `DATABASE_URL`، `JWT_SECRET` و `OTP_SECRET` را قبل از اجرا در `.env` تنظیم کنید. در محیط production از رمزهای قوی و متفاوت استفاده کنید.

### فرانت‌اند

```bash
cd crm-frontend
npm ci
npm run dev
```

برای دمو با داده داخلی:

```bash
VITE_DEMO_MODE=true npm run dev
```

## کنترل کیفیت

```bash
cd crm-backend
npm test
npx prisma validate

cd ../crm-frontend
npm run build
```

هسته محاسبه امتیاز و کش‌بک، ریزش و مزیت حمل آزمون واحد دارد. مهاجرت‌ها در `crm-backend/prisma/migrations` و داده دمو در `crm-backend/prisma/seed.js` قرار دارد.

## نکات مهم برای راه‌اندازی واقعی

- کلید API و Secret وب‌هوک هپی‌کال را در `.env` تنظیم کنید.
- Scheduler داخلی، تحلیل ریزش و انقضای امتیاز را هر شب ساعت ۲ اجرا می‌کند؛ منطقه زمانی سیستم‌عامل سرور را روی ایران تنظیم کنید.
- HTTPS، نسخه پشتیبان PostgreSQL، مانیتورینگ خطا و محدودسازی دسترسی مدیران الزامی است.
- قبل از عمومی‌سازی، قواعد امتیاز و ارزش ریالی پاداش‌ها باید با مالی و فروش تأیید شوند.
- آستانه حمل رایگان، ارزش ریالی هر امتیاز و سقف تخفیف حمل باید پیش از بهره‌برداری با مدیر مالی نهایی شود.
- دمو برای نمایش محصول است؛ داده‌های داخل آن واقعی نیستند.
